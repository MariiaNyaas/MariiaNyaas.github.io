# Mariia Nyaas — Three-Level Portfolio Navigation

## Important
This package updates ONLY the main portfolio repository (`MariiaNyaas.github.io`). Do not upload this package to either of the two individual research repositories.

## Contents
- `index.html` — refreshed homepage preserving design, about and Connect, with six domain links.
- `credit-risk/index.html` — dedicated library with both existing studies, search, and topic filters.
- `financial/index.html`, `accounting/index.html`, `governance/index.html`, `business/index.html`, `public-finance/index.html` — domain landing pages ready for future publications.

## Upload
1. Open https://github.com/MariiaNyaas/MariiaNyaas.github.io
2. Use **Add file → Upload files**. Drag the **contents** of the unzipped folder (the root `index.html` and six folders), not the ZIP itself.
3. Verify the root has `index.html` plus the six domain folders. Commit changes. If GitHub cannot upload all items at once, upload the homepage file, then each folder separately.
4. Check **Settings → Pages** is set to `main` / `/(root)`.
5. Check https://mariianyaas.github.io/credit-risk/ and the homepage.

The individual dashboards stay published under their existing separate repositories.
